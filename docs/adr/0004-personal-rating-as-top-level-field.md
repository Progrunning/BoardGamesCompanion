# Personal rating stored as a top-level BoardGameDetails field, not under BoardGameSettings

Board games can now carry a user's personal 1–10 rating (issue #170), which must apply to any game — owned, wishlisted, played, or none of those. `BoardGameSettings` looks like the obvious home since it already holds per-game, user-authored preferences, but it exists specifically to configure collection-entry scoring (`gameFamily`, `averageScorePrecision`, `gameClassification`) and is only meaningful once a game has a collection entry. Since a personal rating must work for games with no collection entry at all, it's stored as a new top-level nullable field on `BoardGameDetails`, parallel to the existing BGG-sourced `rating`/`votes` fields, rather than nested inside `BoardGameSettings`.
